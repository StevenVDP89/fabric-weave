# Code of conduct

Fabric Weave is a community project and is not operated by Microsoft. Be respectful and constructive in issues, pull
requests and discussions, and assume good faith.

If someone's behaviour in this repository is a problem, tell the maintainers through a private message or a private
security advisory on GitHub. Do not send reports about this project to Microsoft's Open Source Code of Conduct
contact: Microsoft does not run this repository.

The Rayfin app template that this folder was created from shipped the Microsoft Open Source Code of Conduct
(https://opensource.microsoft.com/codeofconduct/). That text applies to Microsoft's own repositories and has been
replaced here for that reason.
